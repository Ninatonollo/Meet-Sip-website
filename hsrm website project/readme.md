# Meet&Sip

## Project Overview

Meet&Sip is a website concept developed during the KimPim Hackathon as part of a university web development project.

The goal was to create a platform that encourages students to connect through regular café meetups. As an interactive element, users can solve a puzzle to receive a discounted coffee voucher.

## Project Details

- **Type:** University hackathon project
- **Development:** Team project
- **Target group:** Students
- **Technologies:** HTML, CSS, JavaScript, Git & GitHub

## Features

- Responsive website concept
- Interactive puzzle feature
- Student-focused user experience
- Café meetup platform concept
